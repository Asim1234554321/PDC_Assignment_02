This program shows inheritance and polymorphism. TradeEvent is the parent class that stores the sender, time and price, and it has a basic dispatch() method that prints these details. FIXOrderEvent and ReutersQuoteEvent extend it and each replace dispatch() with their own version. The FIX order calculates the cost of buying shares, adds the 0.15% exchange fee, and prints the total. The Reuters quote prints the bid, the ask and the spread between them. In TradingEngineApp, all three objects are held in TradeEvent variables, but when dispatch() is called, Java runs the version that belongs to the real object. This is runtime method overriding.
