Question 6: Inventory concurrency benchmark. This program compares two thread-safe maps under heavy use. Ten worker threads each do 50,000 operations on a catalog of products, randomly mixing stock lookups and stock updates. The first test uses Collections.synchronizedMap, which has one lock for the whole map, so threads must wait in a line. The second test uses ConcurrentHashMap, which locks only a small part of the map, so threads working on different products run at the same time. The program measures the time and prints the throughput in operations per second. The concurrent map is usually faster because there is less waiting, and a warm-up run is done first so the timing is fair.
