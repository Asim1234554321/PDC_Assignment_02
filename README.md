Question 2: Packet symmetry. This program checks whether a text is a palindrome using a stack and a queue that were built by hand with arrays. Every character of the packet is pushed onto the stack and added to the queue at the same time. A stack gives back the last character first, and a queue gives back the first character first. The program removes one character from each, compares the two, and prints MATCH or MISMATCH. If every pair matches, the text reads the same forwards and backwards, so the packet is symmetric. If even one pair differs, it is not.
