Question 4: Fork/Join portfolio engine. This program uses Fork/Join to process a large list of asset values in parallel. ParallelRiskCalculator adds up all the values: if its part of the array is 1000 elements or fewer it adds them directly, otherwise it splits into two halves, runs both with fork(), and adds their answers with join(). PortfolioThresholdTask also splits the array, but it changes the values in place, reducing every value above the risk cap by 5%. The main program creates 10,000 random values, runs both tasks in a ForkJoinPool, compares the time with a normal loop, and prints the total risk and the speedup. With only 10,000 elements the speedup may be small, because creating tasks costs time too.
