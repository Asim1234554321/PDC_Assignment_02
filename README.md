Question 5: Parallel min/max sensor search. This program finds the lowest temperature and the highest vibration among 50,000 sensor readings using several threads. SensorSearchEngine is an abstract parent class that stores the data and the range, and it declares an empty processGrid() method. ParallelMinSearch and ParallelMaxSearch each fill in that method. They split the array into four parts, start four threads that each find the min (or max) of their own part, wait for them, and then pick the best result from the four partial answers. The main program runs the min search and the max search at the same time, then prints the critical values and how long it took.
