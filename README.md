Question 7: Cache locality benchmark. This program shows that the order in which you read a 2D array changes the speed. It creates a 2000 x 2000 matrix and adds up all its values in two ways. Row-major reads along each row, which is how the data is stored in memory, so the CPU loads a block of neighbouring numbers into its cache and uses all of them. Column-major jumps down the columns, so each read lands far away in memory and mostly misses the cache. Both do the same number of additions, but the program times each one over 10 runs and prints the speedup. Row-major is faster because of spatial locality, which means that nearby data is already in the cache when it is needed.
